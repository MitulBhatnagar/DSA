# 🚀 Daily DSA Practice

Welcome to my Data Structures and Algorithms (DSA) repository! I created this space to track my daily progress, improve my problem-solving skills, and maintain consistency in coding. 

Every day, I solve and upload a few DSA questions from platforms like LeetCode, GeeksforGeeks, and Codeforces.

## 🎯 Goals
* Solve at least **1-3** problems every day.
* Master core data structures (Arrays, Linked Lists, Trees, Graphs, etc.).
* Improve algorithmic thinking and time/space complexity## 📂 How This Repo is Organized

To keep track of my daily streak, this repository is organized chronologically. 
  
Each daily folder contains the solution file along with a brief `notes.md` explaining the time and space complexity of the approach. optimization.
